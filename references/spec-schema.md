# `spec.json` 字段规范（技能的唯一中间产物）

> Agent 的**唯一创作工作**就是写出这份 JSON；之后全部由脚本确定性渲染，避免提示词漂移。
> 完整可运行示例：`examples/如梦令_spec.json`（原文案例，逐字复刻）。

---

## 1. 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `schema_version` | int | ✅ | 固定 `1` |
| `title` | str | ✅ | 完整标题，如 `如梦令·常记溪亭日暮` |
| `author` | str | ✅ | 作者；佚名写 `佚名` |
| `dynasty` | str | ✅ | 朝代 |
| `genre` | str | ✅ | 诗 / 词 / 曲 / 古文片段 |
| `preset` | str | ✅ | `style-bible.md` §4 的六个 key 之一 |
| `poem_lines` | str[] | ✅ | 原文逐句（保留标点），用于朗读与字幕 |
| `duration` | int | ✅ | 默认 `30`（4~30） |
| `aspect_ratio` | str | ✅ | 默认 `16:9` |
| `resolution` | str | ✅ | 默认 `1080p` |
| `story` | str | ✅ | 一句话梗概，说明事件与情绪怎样变化 |
| `mood_arc` | str | ✅ | 情绪弧线，用 `→` 连接 3–4 段 |
| `adaptations` | str[] | ✅ | 为影像新增的内容（原文没有的），逐条列出；无则 `[]` |
| `time` | str | ✅ | 时间段，如 `夏日晚暮` |
| `season` | str | ✅ | 季节 |
| `place` | str | ✅ | 地点 |
| `palette` | object | ✅ | `garment` / `environment` / `light` / `accent` 四个字符串 |
| `protagonist` | object | ✅ | 见 §2 |
| `scenes` | object[] | ✅ | **恰好 3 个**，见 §3 |
| `shots` | object[] | ✅ | **恰好 6 个**，见 §4 |
| `style_block` | str | ✅ | 从 `style-bible.md` §1 复制，可按预设微调光色 |
| `beauty_block` | str | ✅ | 从 `style-bible.md` §2 复制 |
| `negative_global` | str | ✅ | 从 `style-bible.md` §3 复制 |
| `sound_bed` | str | ✅ | 生成期保留的自然音效描述 |
| `narration` | object | ✅ | `voice`（edge-tts 音色）、`rate`（如 `-10%`）、`lines`（与 `poem_lines` 对应的朗读句） |
| `continuity` | str | ✅ | 贯穿全片的方向/道具/光色一致性声明，如 `木舟始终朝画面右前方缓慢漂行，木桨全程静止搁在舟侧` |
| `video_tail` | str | ⭕ | 覆盖默认画质尾句；不填则用 `style-bible.md` §8 |

## 2. `protagonist`

```json
{
  "identity": "二十岁左右成年年轻女子，身形匀称修长，肩颈自然舒展",
  "face": "柔和鹅蛋脸，眉形舒展，杏眼清亮，鼻形秀气，唇色自然，妆容清淡，保留细腻真实的皮肤纹理，神情平静，嘴角略有笑意",
  "hair": "黑发松松挽成朴素低髻，一支小巧浅木色素簪横向固定，鬓边少量柔软碎发",
  "outfit": "<该预设的服装一致性长句>",
  "props": ["小陶酒壶", "酒杯", "木桨"],
  "taboo": "无其他头饰，无耳饰，无项链；所有衣服无刺绣无花纹无渐变色"
}
```

> 若诗词**不适合出现人物**（如《江雪》的极简空镜），仍要写 `protagonist`（可设为远景中极小的蓑笠翁），并在 `shots` 里让多数镜头为纯环境镜；三视图照常生成，用于「万一出现人物」的一致性锚点。

## 3. `scenes`（恰好 3 个）

```json
{
  "key": "A",
  "name": "临水溪亭",
  "role": "开场环境",
  "detail": "夏日傍晚，溪水旁一座朴素木亭，木柱、灰瓦，亭内一张矮木桌。亭前有可停泊小型无篷木舟的低矮临水石阶，岸边树木形成疏落遮挡，远处零星荷叶。空间关系清楚，亭子、石阶与水面互相连通。",
  "light": "柔亮的低角度侧逆光，深橄榄绿树影，暖木色与淡米杏色亮部，水面细碎反光",
  "avoid": "宫殿、仙侠建筑、现代设施、浓雾、文字、水印、人物"
}
```

- `key` 必须是 `A` / `B` / `C`，分别对应开场 / 行进 / 结尾。
- `detail` 必须写清**空间关系**，B 必须写清**运动方向**，C 必须留出**开阔天空**。
- 三张图一律 `16:9 横屏、无人物、无鸟`（脚本会自动追加）。

## 4. `shots`（恰好 6 个，`seconds` 之和 = `duration`）

```json
{
  "n": 3,
  "seconds": 5,
  "name": "兴尽回舟",
  "size": "中景",
  "start": "女子已在亭外木舟中坐稳，木桨静止搁在舟侧，溪亭在身后",
  "action": "木舟缓慢朝画面右前方漂行，她由轻轻回望溪亭转向前方水路；本镜不发生划桨动作",
  "camera": "固定机位，人物偏左",
  "end": "溪亭逐渐留在身后，前方开始出现零星荷叶",
  "link": "延续同一木舟与右前方行进方向，切到更密的荷塘",
  "ref_scene": "B",
  "line": "兴尽晚回舟",
  "subtitle": "兴尽晚回舟，",
  "sound": "轻微水声、木舟与水面摩擦声",
  "risk": "木桨易被模型误读为划动，必须写明静止搁置"
}
```

**硬规则**（`validate_spec.py` 会卡）：

1. `n` 从 1 到 6 连续；`seconds` 之和必须等于 `duration`。
2. **一镜一个主要动作**，禁止「先…再…然后…还…」的多动作串联。
3. `action` 里凡涉及道具，写清静止或唯一动作，消除歧义。
4. `link` 必须交代与下一镜的衔接（视线 / 动作 / 方向）；第 6 镜写结尾收束。
5. `ref_scene` 取值 `A` / `B` / `C`；通常 `1→A, 2→A, 3→B, 4→B, 5→B, 6→C`。
6. `subtitle` 可为空字符串（纯空镜），但**至少 4 镜有字幕**。
7. 至少一个镜头写明「本镜不出现人物」用于结尾舒展（通常是第 6 镜）。
8. `camera` 用稳定运镜：固定机位 / 轻微上抬 / 缓慢横移 / 缓慢推近，禁止大幅晃动与花哨转场。

## 5. 生成时会渲染出的文件

| 文件 | 内容 |
|---|---|
| `prompts/01_主角三视图.txt` | 三视图生图提示词 |
| `prompts/02_场景A_*.txt` … `02_场景C_*.txt` | 3 条场景生图提示词 |
| `prompts/03_Seedance2.5_视频提示词.txt` | 30 秒主提示词（`@图片1..4` 绑定 + 六镜 + 声音 + 负向 + 规格） |
| `prompts/03b_分段A.txt` / `03c_分段B.txt` | 2×15s 降级用（1-3 镜 / 4-6 镜） |
| `分镜表.md` | 可读分镜表（编号/时长/景别/起止/动作/运镜/衔接/对应诗句） |
| `字幕.srt` | 按镜头时间轴生成 |
| `timeline.json` | 每镜起止秒 + 字幕文本，供后期对齐朗读 |
| `朗读稿.txt` | 全诗朗读文本 |
| `manifest.json` | 资产清单、VideoGen 调用参数、ARK 调用参数、后期参数 |

## 6. 写 spec 时的自检清单

- [ ] 原文逐字核对过（不确定的诗句先查 `poem-library.md` 或联网核对，不编造）
- [ ] 保留原诗**事件顺序**与情绪变化，没有加爱情支线 / 仙侠 / 惊险逃生
- [ ] `adaptations` 如实列出所有新增人物、道具、动作
- [ ] 三张场景的空间能走通，运动方向从 B 一路贯穿到第 6 镜
- [ ] `continuity` 与 B 的运动方向一致
- [ ] 6 镜秒数合计 = 30
- [ ] 至少一镜是纯环境/飞鸟收尾
- [ ] `narration.lines` 与 `poem_lines` 一致（只在末尾补标点，不改字）
