# 美学圣经 · 「超级美丽 + 浪漫感」的硬标准

> 本文件是**唯一风格事实来源**。所有生图提示词、场景提示词、视频提示词都必须逐字引用本文件对应预设的风格块。
> 提炼自《实测 Seedance 2.5 制作古诗词 AI 短片，有点浪漫！》原文提示词 + 原文成片截图 + 火山方舟 Seedance 2.5 官方提示词指南。

---

## 0. 三条不可违背的铁律

1. **写实电影，不是插画。** 写实古装电影质感、真实皮肤纹理、真实木纹石纹水波、真实布料褶皱与透光。禁止插画感、游戏 CG 感、3D 建模感、服装效果图。
2. **通透，不是浓艳。** 柔亮低角度侧逆光 + 面部自然柔和补光。亮部通透、暗部有层次；绿植保持深橄榄绿，衣料保持奶白/浅青/浅杏，**不整体染成浓重橙黄色**。
3. **含蓄，不是煽情。** 一镜一个主要动作，微表情、微风、碎发、衣袖、涟漪、落花、飞絮。禁止夸张表情、大哭大笑、华丽转场、仙侠特效、瞳孔发光、慢镜头滥用。

## 1. 通用风格块 `style_block`（所有提示词必附）

```
写实古装电影质感，东方古典美学，16:9 横屏。柔亮低角度侧逆光穿透发丝与细薄纱衣袖，形成柔和金色轮廓光；面部有自然柔和补光，肤色温润通透。亮部清润通透、暗部保留层次，真实皮肤纹理、真实木纹石纹与水波细碎反光。低饱和东方色，画面留白舒展，三分法构图，前景少量虚化叶片营造纵深，缓慢克制的摄影机运动，含蓄安静的诗意与浪漫气息，胶片级细腻层次。
```

## 2. 浪漫强化块 `beauty_block`（所有提示词必附）

```
极致唯美：夕照或月色在发梢、纱袖边缘与水面形成细碎柔光，微风持续轻动衣袖、碎发、纱帘与枝叶，水面细碎涟漪反射柔和光点；空气中有极淡的浮尘与光晕，远近层次分明，空气感清润；情绪克制留余韵，画面干净高级，如一首看得见的诗。人物为正常人眼、不发光，情绪用微表情表达，不使用任何特效化表现。
```

> `beauty_block` 里「人物为正常人眼、不发光」是官方踩坑项：Seedance 2.5 对强烈情绪词会过度响应导致瞳孔发光，必须前置硬约束，并把「狂喜/极度震惊」改写为「惊叹/微微一怔」。


## 5. 主角三视图固定骨架（不可省略的约束）

无论哪套预设，三视图提示词必须包含以下 6 组硬约束（原文验证有效，能显著降低换脸换衣）：

1. **同一人**：「同一位成年人物的全身三视图，横向排列，从左到右分别为正面、左侧面、背面。三个人像是同一个角色的不同角度，身高、体型、服装、发型和配饰完全一致。」
2. **等比例**：「三个全身人像等比例、等大小、等间距，头顶和脚底分别对齐。从头顶到鞋底完整入画，人物之间不重叠，衣袖不越入相邻人物区域。」
3. **姿势**：「三个视角均自然站立，身体直立、双肩放松，双臂略微离开身体，双手自然下垂，不遮挡腰部服装结构。正面朝向镜头，侧面严格转向左侧，背面完全背向镜头，不回头。」
4. **纯背景**：「干净的浅暖灰色无缝背景，无场景、无道具。均匀柔和的摄影棚光线，肤色自然，衣料颜色准确，暗部清楚。不使用强逆光、浅景深虚化或浓重滤镜。」
5. **定妆照属性**：「精致自然的古装角色定妆照，不是插画、游戏角色或服装效果图。画面无文字、无角度标签、无水印。」
6. **负面清单**：三个不同人物、不同衣服、不同发型、夸张身材、浓妆、复杂珠翠、透明内搭、赤脚、手部变形、肢体缺失、人物裁切、视角混乱。

> 官方补充：Seedance 2.5 在 1–5 个主体时单视图/多视图均可；**不要把三视图直接当成视频画面**。视频提示词必须写明「不要复制人物资产图的白底、拼板排版或重复人像」，否则会把三个人像一起搬进画面。

## 6. 场景定样图固定骨架

- 3 张，分别对应**开场 / 行进 / 结尾**的空间，互相之间有可走通的位置关系。
- 全部 **16:9 横屏、无人物**（结尾镜若需鸟，场景图里也不要出现鸟，避免模型把鸟当成常驻主体）。
- 必须写清「空间关系」「光位」「色板」「真实材质」「避免项」。
- 场景 A 要交代主角与载具/出入口的连接（亭子—石阶—水面—木舟互相连通）。
- 场景 B 要留出**运动方向**（如「木舟斜向朝右前方，舟前留出曲折水路」），这个方向必须一路贯穿到视频提示词。
- 场景 C 要留出**开阔天空**，供结尾镜头上抬。

## 7. 从原文提炼的 5 个真实踩坑

| # | 坑 | 根因 | 本技能的规避写法 |
|---|---|---|---|
| 1 | 一个镜头一个 5s 视频，人物场景全崩 | 多次独立生成无法保持一致 | **单次 30 秒直出**，4 张参考图一次传入，六镜写在同一条提示词里 |
| 2 | 船桨自己划起来 | 「木桨搁在舟侧」表述模糊产生歧义 | 道具状态一律写成「静止、搁置、人物不触碰」并明确「本镜不发生划桨动作」 |
| 3 | 白底拼板三视图被搬进视频 | 未声明资产图只作形象参考 | 视频提示词首段写「不要复制人物资产图的白底、拼板排版或重复人像」 |
| 4 | 镜头衔接断裂 | 视线/运动方向/场景位置不连贯 | 每镜强制写「起始状态 / 一个主动作 / 摄影机运动 / 结束状态 / 与下一镜的衔接」，并统一运动方向 |
| 5 | 加了原词朗读和配乐反而干扰 | 生成期塞入旁白容易诱发字幕 | **生成期一律「无对白、无旁白、无背景音乐、无字幕」**，朗读与配乐全部留到后期 ffmpeg 阶段 |

## 8. 画质与稳定性尾句（每条视频提示词结尾必附）

```

```
